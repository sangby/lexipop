### 踩坑记录

1. **当前执行环境的 HTTPS 请求在 TLS 初始化时失败。** 调用 OpenRouter 模型列表时，.NET 报 SSL 连接错误；`curl.exe` 对同一端点返回 `SEC_E_NO_CREDENTIALS (0x8009030e)`。这说明本次失败发生在请求到达模型接口之前，不能据此判断「抓取模型」的接口逻辑是否正确。先在普通 PowerShell 中重试，再按 [TLS 排查指南](NuGet-schannel-TLS-排查指南.md)检查运行环境和 SChannel；不要为了让测试通过而关闭证书校验。**状态：待在普通运行环境验证。**
2. **Git 将当前运行账户视为非仓库所有者。** 直接执行 Git 命令会触发 `dubious ownership`；本次使用命令级 `git -c safe.directory=C:/Users/Sangby/Desktop/code/dsh-free/lexipop ...` 完成检查和提交。受限环境还可能提示无法读取用户级 `.config/git/ignore`，但本次仓库内 `.gitignore` 正常生效。**状态：本次提交已完成；后续换环境时重新确认所有权。**
3. **构建脚本不能假定项目内始终有 SDK。** SDK 可能安装在系统 PATH，也可能只在仓库的 `.dotnet` 目录。`build.ps1` 现在优先找 `dotnet.exe`，找不到才回退到项目内 SDK；`run.vbs` 也支持 PATH 回退。**状态：构建通过。**
4. **WPF 不能直接套用浏览器 CSS。** 自定义主题实现为读取 CSS `:root` 中约定的变量，再映射到 WPF 的 `DynamicResource`。当前仅支持模板列出的变量、十六进制颜色以及 `0px` 至 `32px` 的圆角；任意 CSS 选择器和布局规则不会生效。保存前会校验变量，避免无效主题在运行时破坏界面。**状态：解析验证通过，视觉效果待手工验收。**
5. **提供方的模型列表不等于可用于翻译的模型列表。** `/models` 返回的是模型 ID，可能包含不支持文本 Chat Completions 的模型。设置页保留手动输入，并提示用户选择文本聊天模型；真正的翻译调用仍需针对所选提供方和模型验证。**状态：待真实接口验证。**
6. **单实例机制会影响新版本的界面验收。** 本机此前有另一位置安装的 LexiPop 进程运行；此时启动新构建可能只通知旧实例打开设置，看到的仍是旧界面。手工验收前需确认旧进程已退出，再从当前构建目录启动。**状态：待手工验收。**

后续遇到新问题时，在本节追加“现象、原因或当前证据、处理方式、验证状态”，避免把推测写成已确认的根因。

## 2026-11-24：第一次迭代后的运行问题

### 踩坑记录

1. **受限启动让三个功能同时失效。** 实际日志显示进程完整性为 `low(S-1-16-4096)`；主题目录写入被拒绝，托盘 `NIM_ADD` 返回错误 5，热键取词出现 UI Automation 访问错误并且剪贴板兜底没有取到文本。修复后，低完整性进程会在占用单实例锁之前提示并退出。应从 Windows 文件资源管理器正常启动。**状态：日志已确认共同运行条件；正常桌面会话中的托盘与划词交互仍待验收。**
2. **后台 `dotnet.exe` 实例容易被漏查。** 旧实例通过 `dotnet.exe LexiPop.dll` 启动，进程名不是 `LexiPop`；托盘注册失败后也没有可见的退出入口。它一直持有单实例锁和构建目录的 DLL，导致新实例立即退出、重新构建报文件占用。本次已核对命令行并关闭该残留实例。**状态：构建恢复正常。**
3. **托盘协议版本设置调用错误。** 代码在添加图标后把版本号交给了 `NIM_MODIFY`，实际应调用 `NIM_SETVERSION`。现已修正并记录版本设置失败时的错误码。**状态：编译通过；正常桌面会话中的托盘显示和点击待验收。**
4. **当前自动化通道无法完成新构建的界面验收。** 桌面自动化按程序名误打开了旧安装位置，按新文件路径启动则被访问控制拒绝；另一条启动尝试被 Windows 取消。未绕过系统拦截。已在可访问用户数据目录的环境中验证自定义主题文件保存、读取、列表流程，测试文件已清理。**状态：主题数据流程通过；设置页、托盘和划词仍待手工验收。**
