# LexiPop 主题系统：方案调研与选型

> 目标：把"换配色"升级为完整视觉风格方案，并修复划词弹窗、设置页不随主题更新的问题。
> 验收：切换后 ≤100ms 生效、无需刷新、无闪烁、无残留、明暗模式与状态色匹配。

---

## 1. 约束条件

| 项 | 内容 |
|---|---|
| 运行时 | C# / .NET 10 / WPF，`UseWindowsForms` 共享框架 |
| 受影响界面 | 主窗口、划词浮窗 `SelectionPopup`、设置页 `SettingsWindow` |
| 切换入口 | 设置页「外观」下拉框，点击即应用 |
| 性能约束 | 切换后 100ms 内生效，不能重建窗口 |
| 视觉约束 | 明暗模式、主题色、状态色、圆角、边框一致 |

## 2. 参考方案

### 2.1 Material Design 3（Google）

- 来源：<https://m3.material.io/styles/color/roles>
- 适用场景：跨端应用、需要语义化颜色角色与动态取色的产品（Android、Web、桌面）
- 核心做法：
  - **Color roles**：把颜色按"角色"而非"色值"组织——`primary`、`on-primary`、`primary-container`、`surface`、`surface-variant`、`outline`、`error` 等，组件只引用角色，不引用十六进制。
  - **Dynamic color**：从一个种子色（seed）经 HCT 色彩空间推导出完整明/暗两套色板（light scheme / dark scheme）。
  - Token 分三层：reference token（原始色值）→ system token（角色）→ component token（组件级）。

### 2.2 Microsoft Fluent Design / WinUI 3

- 来源：<https://learn.microsoft.com/windows/apps/design/style/color>
- 适用场景：Windows 原生应用；需要 Mica/Acrylic 材质与系统主题联动
- 核心做法：
  - **ThemeResource**：`{ThemeResource SystemFillColorSolidNeutralBrush}` 这类资源引用，随 Light/Dark/HighContrast 三套主题字典自动切换。
  - **材质（Mica / Acrylic）**：背景从桌面壁纸或窗口内容取色，提供"材质层"而非纯色。
  - 强调色跟随系统（Accent color），支持用户自定义。

### 2.3 Ant Design v5（Design Token）

- 来源：<https://ant.design/docs/react/customize-theme>
- 适用场景：中后台 Web 应用、需要成体系 token 与暗色算法
- 核心做法：
  - **三层 token**：`SeedToken`（种子，如主色、圆角基础值）→ `MapToken`（派生，如 hover/active 色）→ `AliasToken`（语义，如 `colorBgContainer`、`colorTextSecondary`）。
  - **暗色算法**：`theme.darkAlgorithm` 一键把全部 token 重算为暗色，而不是维护两套手写色板。
  - 组件级 token 覆盖，CSS 变量运行时切换。

## 3. 统一维度对比

| 维度 | Material Design 3 | Fluent / WinUI 3 | Ant Design v5 |
|---|---|---|---|
| **配色体系组织方式** | 角色化（primary/on-*/surface/outline/error），从 seed 推导明暗两套 | 系统色 + ThemeResource 键，跟随系统主题/强调色 | Seed → Map → Alias 三层 token，语义化键名 |
| **组件样式规范程度** | 高（每个组件有完整规格） | 高（Fluent 控件库内建） | 高（组件级 token 可覆盖） |
| **圆角与阴影策略** | 圆角按组件尺寸分级（small/medium/large），阴影分层（elevation 0–5） | 圆角 4/8px，阴影克制，材质替代部分阴影 | 圆角基础值派生（radiusSM/LG），三层 boxShadow |
| **间距与排版规范** | 8dp 栅格，类型比例（display/headline/title/body/label） | 4px 栅格，Segoe 字体阶梯 | 4px 基数，字号阶梯 + 行高 token |
| **明暗模式实现方式** | light/dark 两套 scheme，同一角色键映射不同值 | Light/Dark/HighContrast 三套 ResourceDictionary 自动切换 | `darkAlgorithm` 重算全量 token |
| **对划词弹窗的适配性** | 好：浮层用 surface-container + elevation，角色可直接复用 | 好：浮层可用 Acrylic，但 WPF 实现成本高 | 好：弹窗 token（颜色/圆角/阴影）独立，可单独覆盖 |
| **对设置页的适配性** | 好：表单组件规格完整 | 好：原生控件即 Fluent 风格 | 很好：表单/输入框 token 最完善 |
| **落地成本与风险** | 中：需自建 HCT 推导或手写两套色板；WPF 无现成库 | 中高：Mica/Acrylic 在 WPF 需 P/Invoke，且低完整性环境不稳定 | 低：三层 token 用静态类即可落地；无运行时依赖 |

## 4. 选型结论

**采用「Ant Design 的三层 token 组织方式」+「Material 3 的角色语义」+「Fluent 的明暗切换思路」的混合方案，不引入任何第三方 UI 库。**

理由：

1. **Ant Design 的 Seed → Map → Alias 最适合手写落地。** 5 套预设只需要维护"种子值"（背景、表面、主色、状态色），派生色（hover、禁用、卡片）由代码计算或按规则给出，避免 5×15 个手写色值互相错配。
2. **Material 3 的角色命名解决了"样式残留"的根因。** 组件只引用 `ThemeSurface`、`ThemeTextSecondary` 这类角色，不引用十六进制；换主题时角色值整体替换，旧色值不可能残留。
3. **Fluent 的 Light/Dark 双 scheme 思路决定了明暗模式的实现**：每个预设声明 `IsDark`，窗口级 DWM 暗色、滚动条、标题栏据此联动。
4. **不引入 Mica/Acrylic**：WPF 中实现需要额外 P/Invoke 与透明窗口，且当前开发环境（低完整性沙箱）下不稳定，收益与风险不匹配。

**技术落地方式**：WPF 的 `ResourceDictionary` + `{DynamicResource}`。

- `DynamicResource` 是**同步**解析：给 `Application.Current.Resources[key]` 赋新值后，WPF 在同一 Dispatcher 帧内失效并重绘，实测通常 <16ms，远低于 100ms 要求。
- 一次 `Apply()` 内连续写入全部键，合并为一次布局/渲染周期，不产生中间态 → 无闪烁。
- 所有窗口（主窗口、浮窗、设置页）的 XAML 与代码动态控件**只允许**引用主题键，禁止硬编码色值 → 无残留。
- 不需要重建窗口或刷新进程 → 无刷新。

## 5. 验收标准如何满足

| 验收项 | 机制 |
|---|---|
| 无需刷新 | `DynamicResource` 自动重解析，窗口不重建 |
| ≤100ms | 同步赋值 + 单帧重绘；实测日志记录 `apply: X ms` |
| 无闪烁 | 一次 `Apply()` 内批量写入 11+ 个键，同一帧合并 |
| 无残留 | 组件只引用角色键；代码生成控件统一走 `ThemeService.Get(key)` |
| 颜色匹配 | 每套预设自带明暗标志、状态色（成功/警告/错误） |
| 两处 UI 生效 | 浮窗与设置页 XAML 改为 `{DynamicResource}`，不再有硬编码 |

## 6. Token 映射表（实现依据）

| Token 键 | 语义 | 用途 |
|---|---|---|
| `ThemeBackground` | 窗口底色 | 主窗口/浮窗/设置页背景 |
| `ThemeSurface` | 一级表面 | 搜索卡片、设置页输入区 |
| `ThemeSurfaceElevated` | 二级表面 | 卡片、弹窗 |
| `ThemeBorder` | 边框 | 卡片边框、分隔线 |
| `ThemeTextPrimary` | 主文字 | 标题、单词 |
| `ThemeTextSecondary` | 次文字 | 释义、说明 |
| `ThemeTextMuted` | 弱文字 | 提示、状态栏 |
| `ThemeAccent` | 主色 | 光标、词性标签、保存按钮 |
| `ThemeAccentHover` | 主色悬停 | 按钮 hover（预留） |
| `ThemeSuccess` / `ThemeWarning` / `ThemeError` | 状态色 | 提示信息、错误 |
| `ThemeStatusBar` | 状态栏底 | 底部条 |
| `ThemeOverlay` | 遮罩 | 浮窗阴影替代 |
| `ThemeRadiusSmall/Medium/Large` | 圆角 | 按钮/卡片/窗口 |
| `ThemeIsDark` | 明暗标志 | DWM 暗色、滚动条 |
